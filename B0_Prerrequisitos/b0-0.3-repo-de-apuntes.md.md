### ⌨️ Comandos y pasos importantes

- `pwd` — Permite comprobar la ruta exacta actual de la terminal para asegurarnos de que estamos dentro de `Trimestre_1` antes de inicializar Git.
    
      
    
- `git init` — Convierte una carpeta normal en un repositorio de Git local.
    
      
    
- `git branch -M main` — Renombra la rama principal por defecto a `main`.
    
      
    
- `git status` — Muestra el estado actual del repositorio y los ficheros modificados o pendientes de añadir.
    
      
    
- `git remote add origin <url-ssh>` — Conecta el repositorio local con el repositorio remoto en GitHub.
    
      
    
- `git add <fichero>` — Prepara (añade al área de intercambio o staging) un archivo específico para ser guardado en el siguiente commit.
    
      
    
- `git commit -m "Mensaje"` — Guarda una "foto" permanente de los cambios preparados con un mensaje descriptivo.
    
      
    
- `git push -u origin main` — Sube los commits locales al repositorio remoto en GitHub por primera vez.
    
      
    
- `q` — Permite salir del paginador (less) cuando la terminal se queda estancada mostrando un historial largo como `git log`.

### 🤔 Respuestas a las preguntas

1. **¿Por qué un repositorio por trimestre?**
    
      
    
    Porque al cerrar cada trimestre el repositorio queda "congelado" y se califica de forma limpia y aislada. Permite tener un enlace claro que se entrega una sola vez, evitando que un problema o lío en un trimestre afecte al trabajo de los demás.
    
      
    
2. **Un día damos teoría suelta, que no pertenece a ninguna fase. ¿Cómo se llamaría esa entrada, y por qué esa sí lleva la fecha cuando las de fase no la llevan?**
    
      
    
    Se llamaría siguiendo la convención de fechas y título corto (por ejemplo, incluyendo la fecha en el nombre del fichero). Lleva la fecha porque al no pertenecer a una fase numerada concreta, la fecha es el criterio fundamental para ordenarla cronológicamente dentro de los apuntes.
    
      
    
3. **¿En qué carpeta EXACTA se hace `git init`?**
    
      
    
    Se hace exactamente dentro de la carpeta del trimestre (`Trimestre_1`), nunca en la raíz de la bóveda (`Boveda_SOR`) ni en la carpeta general de apuntes (`00_Apuntes`), para evitar convertir carpetas no deseadas en repositorios de Git.
