## 🎯 Qué se pedía

Crear y configurar una cuenta en GitHub junto con la instalación de Git local. El objetivo era vincular ambas plataformas para poder gestionar el control de versiones y subir código a la nube.

## ⌨️ Comandos y pasos importantes

- - `git config --global user.name "TuNombre"` — Configura el nombre de usuario global que identificará tus commits.
    
- `git config --global user.email "tu@email.com"` — Asocia tu dirección de correo electrónico a los cambios que realices en Git.
    
- `git --version` — Verifica que Git está correctamente instalado en el sistema.
    
- `ssh-keygen -t ed25519 -C "tu@email.com"` — Genera un par de claves SSH para autenticarte de forma segura con GitHub.
