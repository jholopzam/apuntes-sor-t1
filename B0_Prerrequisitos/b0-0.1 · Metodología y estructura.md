- `mkdir -p b0-prerrequisitos/fase-0.1` — Crea la estructura de directorios necesaria para la fase sin sobrescribir lo existente.
    
- `git status` — Comprueba el estado del repositorio local y los archivos pendientes de seguimiento.
    
- `git add .` — Añade los cambios y nuevos archivos preparados para el commit.
    
- `git commit -m "feat: estructura inicial fase 0.1"` — Guarda el estado de la entrega con un mensaje descriptivo.
